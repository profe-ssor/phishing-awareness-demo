# Phishing Awareness Training Simulation

A static, offline phishing-awareness demonstration for a workshop.

## Safety properties

- The form does not read or transmit entered values.
- No credentials are stored in browser storage or sent to a server.
- Submitting the form only reveals the awareness warning.
- Participants should use fictional details only.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `phishing-awareness-demo`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for deployment. GitHub Pages will show the public site address in Settings → Pages.

If the GitHub username is `profe-ssor`, the expected project-site address is:

https://profe-ssor.github.io/phishing-awareness-demo/

The URL only becomes live after the repository is created and Pages deployment succeeds.

## Important workshop note

Tell participants before the exercise: this is a training simulation; enter fictional details only. Never ask anyone to enter a real password, recovery code, or one-time verification code.
